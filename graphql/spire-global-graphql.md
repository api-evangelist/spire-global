# Spire Global GraphQL API

Single GraphQL endpoint delivering Spire's satellite AIS maritime data - vessel positions, voyages, port calls, and predicted ETAs - with flexible querying for analytics and integration use cases. Now operated under the Kpler maritime brand following the 2024 acquisition.

**Endpoint:** https://api.maritime.spire.com
